# POO-UX

En este repositorio junto con mi compañero Rodrigo Hazel y su servidor Fernando Reyes estamos subiendo nuestras actividades correspondientes a la materia POO impartida por el maestro Abimael Rodríguez Sosa junto con todo lo visto en clase y los 4 pilares de la programación orientada a objetos que son:

    Abstracción
    Encapsulamiento
    Herencia
    Polimorfismo

para compilar usando una clase Main que ejecute nuestro programa primero compilamos todas nuestras clases que vamos a ocupar 
en una sola línea -> javac EquipoTI.java Laptop.java Servidor.java Main.java, luego hacemos "cd.." para salir de esa carpeta actual y desde un nivel más arriba ejecutar -> java proyectoIntegrador.Main, de esta forma nuestro programa correrá desde la terminal o en su defecto hacer click en "run java"
